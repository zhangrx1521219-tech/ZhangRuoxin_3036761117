# Skill: Reproduce Card & Krueger (1994) tables and figures

## Purpose
Generate all main tables and figures for the Card & Krueger (1994) replication
from the raw survey data.

## Inputs
- `data/raw/public.csv` — raw restaurant survey data (410 stores).

## Outputs
- `outputs/tables/table2.csv` — descriptive statistics (waves 1 and 2)
- `outputs/tables/table3.csv` — average employment and DID estimates
- `outputs/tables/table4.csv` — regression models of employment change
- `outputs/tables/extension.csv` — heterogeneity analysis
- `outputs/figures/figure1.png` — distribution of starting wages

## How to run
```bash
python code/run_all.py
```
## Key steps

1. **Construct FTE employment:** `FTE = full-time + managers + 0.5 × part-time`.
2. **Handle store closures:** permanently closed stores (`STATUS2 == 3`) have
   wave-2 FTE set to 0; refused, renovation, and temporarily closed stores
   (`STATUS2` in {0, 2, 4, 5}) have wave-2 FTE set to missing.
3. **Difference-in-differences:** compare FTE employment changes in NJ vs. PA.
4. **Wage-gap variable:** `gap = (5.05 − WAGE_ST) / WAGE_ST` for NJ stores
   initially paying below $5.05, and 0 otherwise.
5. **Extension:** split the sample by binding intensity, chain, and ownership.

## Notes

- All scripts read `data/processed/ck_analysis.csv`, generated by `01_clean.py`.
- `run_all.py` executes all scripts in order; run it from the project root.
